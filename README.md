# SOOP Live Chat Archive (실시간 채팅 아카이브 & 분석 대시보드)

SOOP(아프리카TV) 방송의 실시간 채팅 자동 저장, 24시간 스트리머 방송 감시, VOD 다시보기 채팅 복원, 시청자별 채팅 내역 검색 및 통계 요약 분석을 제공하는 올인원 웹 애플리케이션입니다.

---

## 🌟 핵심 기능

1. **실시간 채팅 자동 아카이브 (Live WebSocket)**
   - SOOP 라이브 방송 소켓에 직접 연결하여 모든 시청자 채팅을 실시간 수집 및 DB 저장
2. **24/7 스트리머 방송 감시 (Auto Monitor)**
   - 등록된 스트리머의 방송 시작 여부를 주기적으로 체크하여 방송 시작 시 자동으로 채팅 녹화 시작
3. **과거 VOD 채팅 복원 & 전용 뷰어 & 파일 저장**
   - VOD 다시보기 채팅 초고속 복원 및 텍스트 로그 파일 업로드/가져오기
   - 실시간 채팅과 분리된 **독립 VOD 채팅 전용 뷰어 & 보관함** 제공 (깜빡임 없이 안정적 조회)
   - 복원 완료 즉시 알림 안내
   - 복원된 채팅을 **TXT(`.txt`), CSV(`.csv`), JSON(`.json`) 파일로 즉시 저장 및 다운로드**
4. **시청자 채팅 검색 & 타임라인 분석**
   - 닉네임/유저ID별 채팅 기록 조회, 시간대별 채팅 빈도 차트, 주요 키워드 및 대화 분석
5. **데이터 내보내기 & 백업**
   - 텍스트/CSV/JSON 파일 다운로드 지원

## 🚀 빠른 시작 (실행 방법)

### 1. 패키지 설치
```bash
pip install -r requirements.txt
```

### 2. 서버 실행
폴더 내 **`run.bat`** 파일을 더블 클릭하거나 콘솔에서 아래 명령어를 실행합니다:
```bash
python app.py
```

### 3. 웹 브라우저 접속
브라우저에서 `http://localhost:8000` (또는 `http://127.0.0.1:8000`)에 접속합니다.
